# 对话测试程序说明

## 测试程序：simulate_otaku_conversation.py

### 用户设定
模拟一个**25 岁男性程序员**的宅男形象：
- **性格**：内向、理性、喜欢独处
- **爱好**：看书、动漫、游戏、编程
- **居住地**：上海
- **喜欢的书**：三体、哈利波特、指环王、1984
- **喜欢的动漫**：进击的巨人、海贼王、鬼灭之刃、命运石之门
- **生活习惯**：经常熬夜（凌晨 2 点睡）、很少运动、喜欢外卖
- **社交风格**：朋友不多但关系很好，有社交恐惧症

### 对话场景库（10 大类，60+ 个问题）

1. **书籍相关** - 讨论喜欢的书籍、阅读习惯
2. **动漫讨论** - 追番情况、喜欢的动漫类型
3. **工作日常** - 程序员工作、远程办公偏好
4. **日常生活** - 作息、饮食、运动习惯
5. **社交生活** - 朋友圈子、社交态度
6. **游戏讨论** - 游戏偏好、熬夜玩游戏
7. **未来规划** - 人生目标、恋爱观
8. **心情情感** - 情绪状态、压力应对
9. **兴趣爱好深挖** - 爱好的意义和影响
10. **回忆往事** - 成长经历、学生时代

### 运行方法

```bash
# 确保后端服务已启动
python -m uvicorn main:app --host 0.0.0.0 --port 8000

# 运行测试
cd C:\myProject\MindPeek
python tests/simulate_otaku_conversation.py
```

### 测试流程

1. **自动对话**：程序会自动发送 100 轮对话到后端 API
2. **特征提取**：后端自动提取用户特征并构建画像
3. **保存记录**：对话记录保存到 `conversation_log_test_otaku_user.json`
4. **显示画像**：测试结束后显示提取的所有特征

### 预期提取的特征

根据用户设定，预期会提取到以下特征：

#### 兴趣爱好
- 喜欢看科幻小说（三体、哈利波特等）
- 喜欢动漫（进击的巨人、命运石之门等）
- 喜欢玩游戏（原神等）
- 喜欢编程

#### 生活习惯
- 经常熬夜（凌晨 2 点睡觉）
- 很少运动
- 喜欢点外卖
- 宅在家里

#### 性格特征
- 内向
- 喜欢独处
- 有社交恐惧
- 朋友不多但关系好

#### 工作特征
- 程序员
- 喜欢远程办公
- 经常加班

#### 个人信息
- 居住在上海
- 25 岁
- 男性

### 查看结果

测试完成后，你可以：

1. **查看前端界面**：
   - 访问 http://localhost:3000/knowledge-graph
   - 查看知识图谱可视化
   - 查看特征列表
   - 查看用户画像

2. **查看对话记录**：
   - 文件：`tests/conversation_log_test_otaku_user.json`
   - 包含所有 100 轮对话的完整记录

3. **API 查看特征**：
   ```bash
   curl http://localhost:8000/api/user/test_otaku_user/features
   ```

### 测试时间

- **100 轮对话**：预计 2-5 分钟
- **特征提取**：后台异步进行，对话结束后再等待 5 秒
- **总计**：约 5-10 分钟

### 注意事项

1. 确保后端服务已启动
2. 确保 LLM API 配置正确
3. 测试过程中可以按 Ctrl+C 中断
4. 中断后对话记录仍会保存

### 自定义测试

你可以修改测试程序来模拟不同类型的用户：

1. 修改 `USER_PROFILE` 字典改变用户设定
2. 修改 `OTAKU_RESPONSES` 改变回复风格
3. 修改 `CONVERSATION_TOPICS` 添加更多话题
4. 修改 `num_rounds` 改变对话轮数

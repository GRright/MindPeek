# Agent 自进化系统设计方案

## 1. 系统概述

MindPeek 的 Agent 系统是一个**多层次、协作式**的智能分析架构。系统通过多个专业 Agent 的协同工作，实现对用户特征的全面挖掘、性格分析、行为预测等功能。Agent 系统采用异步任务编排，支持并发执行，能够在用户对话过程中后台进行深度分析。

### 1.1 核心设计理念

- **专业化分工**：每个 Agent 专注于特定领域，避免功能耦合
- **协作式分析**：通过编排器协调多 Agent 协作，形成完整的分析链路
- **自进化能力**：特征提取和置信度评估能够根据反馈持续优化
- **异步执行**：后台任务不阻塞主对话流程，用户体验流畅

## 2. Agent 详解

### 2.1 FeatureDiscoveryAgent（特征发现 Agent）

**职责**：基于 LangGraph 构建的自主特征发现 Agent，能够动态判断用户特征，自主决定记录哪些特征以及如何分类。

**核心能力**：

1. **自主特征识别**：能够从用户对话中识别预定义的 14 种特征类型，包括 MBTI、大五人格、行为习惯、潜在想法、兴趣爱好、价值观、情感状态、生活偏好、沟通风格、思维模式、社交特点、工作风格、个人信息、社会关系。

2. **新特征发现**：如果用户透露的信息不适合已有分类，Agent 可以提出新的分类建议。

3. **置信度评估**：根据对话中的证据充分程度，评估每个特征的置信度（0-100%）。

4. **去重机制**：避免重复记录已有的相似特征，如果发现重复但新发现的置信度更高，会更新已有特征。

**工作流程**：

```
用户消息 → 分析消息(analyze_message) → 验证特征(validate_features) → 决定存储策略(decide_storage) → 保存到数据库
```

1. **analyze_message**：分析用户最新消息，使用 LLM 深度理解对话内容，提取潜在特征
2. **validate_features**：过滤低置信度特征（<50%），检查重复特征，决定是否需要更新
3. **decide_storage**：根据置信度决定存储优先级，高置信度（≥80%）直接存储，中低置信度需要聚合

**存储优先级策略**：

| 置信度 | 存储优先级 | 是否需要聚合 |
|--------|-----------|--------------|
| ≥80% | 高 | 否 |
| 60%-80% | 中 | 是 |
| <60% | 低 | 是 |

### 2.2 IntentClassifier（意图分类器）

**职责**：基于语义 Embedding 的智能意图判断，使用余弦相似度判断用户消息是否需要个性化处理。

**核心能力**：

1. **双模板匹配**：预置了 20 个个性化模板（如"我最近感觉很焦虑"、"我的性格是怎样的"）和 20 个通用模板（如"什么是人工智能"、"如何学习 Python"）。

2. **语义相似度计算**：使用多语言轻量级模型（paraphrase-multilingual-MiniLM-L12-v2）计算用户消息与两类模板的语义相似度。

3. **自动决策**：如果个性化模板相似度高于通用模板，则该消息需要个性化处理。

**技术实现**：

- 使用 SentenceTransformer 预计算所有模板的 embedding
- 判断时计算用户消息与两类模板的平均相似度
- 返回分类结果和相似度分数

**应用场景**：

- 在用户发送消息时快速判断是否触发个性化对话
- 只有需要个性化的消息才会调用用户画像数据进行增强回答

### 2.3 PersonalInfoAgent（个人信息与关系提取 Agent）

**职责**：从对话中提取用户个人信息和关系信息，包括姓名、年龄、职业、居住地、教育背景、婚姻状况、与他人/事物的关系等。

**核心能力**：

1. **个人信息提取**：识别并提取用户的显性个人信息（姓名、年龄、性别、职业等）

2. **关系网络发现**：识别对话中提到的人物及其关系类型（家人、朋友、同事、恋人等）

3. **并行提取**：同时提取个人信息和关系信息，提高效率

**提取的信息类型**：

| 类别 | 说明 |
|------|------|
| 基本信息 | 姓名、年龄、性别、职业、居住地、教育、婚姻状况 |
| 关系信息 | 人物名称、关系类型、关系描述、置信度 |
| 其他信息 | 爱好、习惯、经历等（带置信度） |

**特点**：

- 只提取对话中**明确提到**的信息，不进行推测
- 使用 JSON 格式返回结构化数据
- 支持批量处理对话历史

### 2.4 MBTIAgent（MBTI 性格分析 Agent）

**职责**：基于用户对话内容，分析推断用户的 MBTI 性格类型。

**MBTI 四个维度**：

| 维度 | 含义 | 两极 |
|------|------|------|
| E/I | 能量来源 | 外向 / 内向 |
| S/N | 信息获取 | 感觉 / 直觉 |
| T/F | 决策方式 | 思考 / 情感 |
| J/P | 生活态度 | 判断 / 知觉 |

**分析流程**：

1. 接收用户对话历史（最近 10 轮）
2. 读取已识别的 MBTI 特征（避免重复分析）
3. 对每个维度进行倾向分析，输出置信度
4. 综合四个维度给出最终 MBTI 类型（如 INTJ、ENFP）

**输出格式**：

```json
{
    "dimensions": {
        "EI": {"tendency": "I", "confidence": 0.85, "evidence": "对话中表现出内敛、喜欢独处思考..."},
        "SN": {"tendency": "N", "confidence": 0.72, "evidence": "关注抽象概念..."},
        "TF": {"tendency": "T", "confidence": 0.68, "evidence": "决策依据逻辑..."},
        "JP": {"tendency": "J", "confidence": 0.75, "evidence": "喜欢计划..."}
    },
    "mbti_type": "INTJ",
    "confidence": 0.72,
    "reasoning": "综合分析..."
}
```

### 2.5 BigFiveAgent（大五人格分析 Agent）

**职责**：分析用户的大五人格特质，提供更全面的人格特征描述。

**大五人格维度**：

| 维度 | 含义 | 高分特征 | 低分特征 |
|------|------|----------|----------|
| 开放性 | 好奇心、创造力 | 富有想象力、好奇 | 务实、传统 |
| 尽责性 | 自律、可靠性 | 有组织、负责任 | 随意、冲动 |
| 外向性 | 社交活跃度 | 开朗、自信 | 内向、含蓄 |
| 宜人性 | 信任他人程度 | 合作、同理心 | 怀疑、冷淡 |
| 神经质 | 情绪稳定性 | 敏感、焦虑 | 稳定、冷静 |

**分析输出**：

```json
{
    "traits": {
        "开放性": {"score": 75, "evidence": "对新技术感兴趣..."},
        "尽责性": {"score": 60, "evidence": "工作有计划..."},
        "外向性": {"score": 45, "evidence": "偏向内敛..."},
        "宜人性": {"score": 80, "evidence": "善于理解他人..."},
        "神经质": {"score": 55, "evidence": "偶尔焦虑..."}
    },
    "dominant_traits": ["开放性", "宜人性"],
    "overall_confidence": 0.78,
    "reasoning": "综合分析..."
}
```

### 2.6 PredictionAgent（行为预测 Agent）

**职责**：基于用户历史特征和行为模式，预测用户未来最有可能的行为或想法。

**预测维度**：

| 类别 | 说明 |
|------|------|
| 行为预测 | 用户可能采取的行动 |
| 想法预测 | 用户可能产生的思考 |
| 情感预测 | 用户可能出现的情绪 |
| 决策预测 | 用户可能做出的选择 |

**时间范围**：

- **短期**（1-7 天）：即将发生的想法或行为
- **中期**（1-4 周）：未来的规划或倾向
- **长期**（1-3 月）：性格相关的行为模式

**预测输出示例**：

```json
[
    {
        "prediction": "用户可能会开始学习一门新技能",
        "category": "行为",
        "confidence": 0.85,
        "reasoning": "用户表现出强烈的好奇心和学习欲望（开放性得分75%），近期对话中多次提到想要自我提升",
        "timeframe": "中期",
        "observable_signals": ["关注在线课程平台", "询问学习建议"]
    }
]
```

**应用**：

- 在 Profile 页面展示用户的行为预测
- 为个性化对话提供参考
- 帮助用户了解自己的潜在行为模式

### 2.7 AsyncAgentOrchestrator（异步任务编排器）

**职责**：管理和调度后台 Agent 任务的异步执行，支持多种任务类型的并发处理。

**任务类型枚举**：

| 任务类型 | 说明 |
|----------|------|
| DEEP_THINK | 深度思考分析 |
| FEATURE_CORRELATION | 特征关联分析 |
| RELATIONSHIP_DISCOVERY | 社会关系发现 |
| PROFILE_UPDATE | 画像更新 |
| MEMORY_CONSOLIDATION | 记忆整合 |
| LATENT_INTENT | 潜在意图发现 |
| STABILITY_EVALUATION | 稳定性评估 |

**核心特性**：

1. **任务队列管理**：支持任务提交、调度、执行、完成的完整生命周期

2. **并发控制**：可配置最大并发数（默认 3 个），避免资源竞争

3. **优先级调度**：高优先级任务可以插队执行

4. **状态追踪**：每个任务都有明确的状态（pending/running/completed/failed）

**异步任务详解**：

**DEEP_THINK（深度思考分析）**：

- 输入：用户消息、对话历史、用户特征
- 处理：结合用户画像进行深度分析
- 输出：分析结果和建议

**FEATURE_CORRELATION（特征关联分析）**：

- 发现特征之间的关联关系
- 构建特征关联图谱
- 识别核心特征和衍生特征

**RELATIONSHIP_DISCOVERY（关系发现）**：

- 从对话中发现新的社会关系
- 更新关系网络
- 评估关系强度

**MEMORY_CONSOLIDATION（记忆整合）**：

- 定期整合用户的碎片化信息
- 强化重要记忆
- 衰减低价值信息

**LATENT_INTENT（潜在意图发现）**：

- 挖掘用户未明确表达的潜在需求
- 分析对话中的暗示和隐喻
- 预测用户可能想问但没问的问题

**STABILITY_EVALUATION（稳定性评估）**：

- 评估用户特征的稳定性
- 检测特征的异常变化
- 判断是否需要重新提取

## 4. 置信度体系

### 4.1 置信度等级

| 等级 | 范围 | 说明 |
|------|------|------|
| 高 | 80-100% | 特征明确，可直接使用 |
| 中 | 60-80% | 需要更多证据支持 |
| 低 | 40-60% | 仅供参考，需要聚合 |
| 待定 | <40% | 证据不足，不记录 |

### 4.2 置信度影响因素

- **证据数量**：对话中提到的次数
- **证据明确性**：表达是否清晰无歧义
- **一致性**：与已有特征是否一致
- **时间因素**：最近的信息可能更准确

## 6. 设计优势

### 6.1 模块化设计

- 每个 Agent 独立负责特定领域
- 便于单独优化和扩展
- 降低系统耦合度

### 6.2 异步非阻塞

- 后台任务不阻塞主对话
- 用户体验流畅
- 资源利用率高

### 6.3 自进化机制

- 置信度体系支持动态调整
- 特征去重避免冗余
- 新特征发现机制

### 6.4 协作式分析

- 多 Agent 协同工作
- 特征关联发现
- 全面立体的用户画像

---

## 7. 未来优化方向

1. **增量学习**：支持在线学习，持续优化特征模型
2. **跨用户迁移**：利用相似用户的特征进行冷启动优化
3. **情感动态追踪**：追踪用户情感状态的时间变化
4. **预测反馈闭环**：验证预测准确性并优化模型
5. **多模态融合**：支持图像、语音等更多数据类型
